# Feature matrix

Statuses reflect this local codebase as of 18 October 2026. “Implemented and tested” means covered by the named local integration suite; it does not certify hosted production readiness or external provider operation. No status implies feature parity with Choppity or Adobe.

| Area | Status | Evidence / remaining work |
|---|---|---|
| Local responsive dashboard, upload/link intake, project cards, server search/filters/pagination | Implemented; browser E2E pending | Library supports archived scope, status/source filters, name search, sorting, and paginated API results; no Playwright/browser automation. |
| All clips library | Implemented; browser E2E pending | Workspace-scoped search across clip/project/transcript text, export filter, pagination, reopen editor and media download actions. |
| Account registration, login, logout, email verification, password reset, account deletion, request throttling and cookie sessions | Implemented; API-tested (SMTP mocked) | Local passwords are hashed; minimum length 12; optional SMTP mode sends expiring one-time verification/reset links, requires verified email for sign-in, and invalidates prior sessions after reset. Account deletion cleans sole-member workspace data/files and retains shared workspace content; owners must transfer shared ownership first. Fixed-window SQLite throttles cover account endpoints; they are single-host only. SMTP delivery, distributed rate limits and managed identity remain unverified/unimplemented. |
| Workspaces, invitation tokens, roles, member removal/ownership transfer and project/planner scope | Implemented and API tested | Owner/admin token creation, email match, expiry, workspace switch, viewer write denial, member removal, explicit owner transfer (old owner becomes admin) and tenant isolation covered by integration tests. UI supports switching, inviting, joining, managing members and transferring ownership. Broader adversarial security tests remain. |
| Upload validation, media probing and source thumbnails | Implemented and API tested | Synthetic MP4 and WAV uploads verify duration, dimensions, frame rate, audio/video presence, thumbnail creation/absence and workspace-protected thumbnail route. Browser uploads use workspace-scoped, offset-checked 8 MiB chunks; the browser resumes the same selected file from the server offset after connection interruption and supports cancellation. Chunk API and workspace authorization are tested; browser E2E remains pending. Stale partial sessions expire after 24 hours. S3 multipart/presigned uploads, cross-device resume, quotas and production object storage remain unimplemented. |
| YouTube source import | Implemented; provider/source test pending | yt-dlp path exists; no real source verification here; access and terms vary. |
| Persistent source-processing jobs, stage tracking, restart recovery, cancellation and bounded retry | Implemented and API tested locally | SQLite job history records attempts, coarse stage/chunk progress, timestamps and errors; queued/running jobs can be canceled, startup recovers interrupted work, and user-triggered retry is capped at three attempts. Cancellation waits for in-flight provider requests to return. Compose separates API and one worker process, but queue/storage are still single-host SQLite/local volume; no leases, multi-worker scaling or dead-letter queue. Recovery may repeat uncommitted work. |
| Timestamped transcription and AI moment selection | Implemented; blocked on external credentials/evidence | Project setup configures language, 5–180-second maximum duration, 1–20 clip count, target platform and starting aspect ratio. Selection prompt includes platform guidance and explicit explainable scoring dimensions, bounds candidates to the transcript source duration, enforces non-overlap and requested result count; output ratio seeds each clip edit. OpenAI integrations exist; require user-provided API key and authorized speech-bearing source; no real provider run verified. |
| Project rename, duplicate, archive/restore, delete | Implemented; archive/lifecycle API tested | Active, archived and all-project filters; archived projects remain restorable; permanent delete remains explicit and warns about source cleanup. |
| Transcript search, correction, soft removal/restore and range drafts | Implemented and API tested | Segment edits are revision checked, persisted, searchable, and used by future clip generation without re-transcribing. Word timestamps are requested and stored when the provider returns them; correction invalidates stale word timing. No automatic text-to-timeline cuts; real provider timing is not yet verified. |
| Versioned clip EDL, zoomable trim/split/reorder timeline, edit history and export | Implemented; API/render tested, browser E2E pending | Saved edits include up to 20 non-overlapping source ranges in user-selected output order, title, crop ratio and manual crop position, captions, up to eight additional positioned audio tracks, an optional music bed/logo and output encoding. The editor offers a zoomable source ruler, draggable in/out handles for the selected segment, split-at-playhead, remove and move-earlier/later controls, synchronized seek playhead, Ctrl+Z/Ctrl+Y, autosave and version restore. FFmpeg concatenates saved segments; tests verify decoded MP4 framing changes with persisted crop positions and caption timing follows reordered clips. No browser E2E. |
| Burned captions, SRT and VTT | Implemented and tested | FFmpeg export decodes a video with karaoke-style word highlighting from persisted timed words; tests verify chunk offsets, styling, legacy EDL upgrades, and static fallback. No visual browser-preview comparison; real provider-produced word timings remain unverified. |
| Ideas board and planned-content calendar | Implemented and API tested | Persistent ideas/status and calendar records; not connected to publishing. |
| Automatic speaker/face tracking and dynamic reframing | Partially implemented | Aspect conversion supports saved manual horizontal/vertical crop focus with matching CSS video preview and FFmpeg crop output; automatic face/speaker detection, tracking, smoothing and keyframes are not implemented. |
| Full multitrack timeline, split/reorder, frame-accurate undo/redo/autosave | Partially implemented | Versioned EDLs support up to 20 non-overlapping video segments ordered for output plus eight independently timed/leveled/faded audio asset tracks; the editor supports splitting, removing and reordering video segments, and FFmpeg concatenates video/audio with caption remapping. Video overlay tracks, frame-accurate operations and live composite preview remain unimplemented. |
| Workspace asset library | Implemented; API/render tested | PNG/JPEG/WebP images and MP3/M4A/WAV audio upload, preview, delete, size/type validation and workspace isolation. Saved clip edits burn a logo and mix an optional audio bed; no reusable templates or font uploads. |
| B-roll, audio/music, transitions, title cards, profanity tools | Partially implemented | Static logo overlay, one looping background bed, and up to eight additional positioned audio tracks render into MP4 with per-track volume and fades. The audio EDL and actual FFmpeg mix are API/render tested. No B-roll/video overlays, transitions, title cards or profanity controls. |
| Workspace Brand Kit caption defaults | Implemented; browser E2E pending | Workspace name, accent/caption colors, supported font, and caption preset are saved; settings populate new versioned clip EDLs and affect FFmpeg export. Logo asset is selected per clip, not configured as a reusable template. |
| Official social OAuth, scheduled publishing | Not implemented | No platform credentials/adapters. Calendar entries are drafts only; no posts are simulated. |
| Analytics | Not implemented | No connected social metrics or analytics storage. |
| Billing, quotas, metering, subscriptions | Not implemented | No payment provider or usage ledger. |
| Multi-tenant AI key separation | Implemented; API-tested | Workspace owners/admins save/remove scoped credentials; Fernet ciphertext is persisted when `CUTROOM_SECRET_ENCRYPTION_KEY` is configured. Local combined mode supports memory-only credentials. Key rotation/managed secrets and real provider execution remain unverified. |
| PostgreSQL, Redis workers, object storage, migrations | Not implemented | Flask + SQLite + local files. |
| Health endpoint and local network guard | Implemented and tested | Health and private static asset allowlist covered. |
| Docker Compose split-process local runtime | Implemented; image build pending | Non-root API and worker containers share the SQLite queue/data volume; internal API-key handoff uses the shared session secret. Worker mode starts against an isolated SQLite database. Includes read-only root filesystems, health check, bounded logs and localhost port binding. Docker is unavailable in this environment, so image build and composed API/worker startup have not been run. Not distributed: one worker, SQLite and local volume only. |
| Integration tests | Implemented; browser/CI coverage pending | Thirty-five Python tests cover CSRF enforcement and cross-origin rejection, auth/workspace isolation, account request throttles and account deletion/file cleanup, SMTP-mode verification/reset tokens and session invalidation (mail mocked), workspace member removal and explicit ownership transfer, trusted Docker CIDR guard and token-protected workspace-specific worker API-key handoff and encrypted key isolation, planner and brand settings, generation preference validation/persistence/duplication and candidate count/platform/source bounds, language-aware word-timestamp transcription offsets, video/audio and resumable chunk uploads (offset conflicts, workspace scope, size checks, completion and cancellation), workspace asset upload/access/deletion and actual logo/music/additional-audio-track FFmpeg mix export, persistent async export progress/private downloads and queued cancellation, queued source-analysis cancellation, CRUD/archive/project and clip library filters, transcript correction/removal/regeneration and timed-word invalidation, concurrent versioned edits, manual crop framing, reordered video concatenation, FFmpeg caption rendering/sidecars and job recovery. No real AI/YouTube/SMTP provider or browser E2E test. |
| Deployment hardening, observability, backup/restore | Not implemented | No production infrastructure or launch runbook. |

The reproducible local test command is `python -m unittest discover -s tests -v`. See `IMPLEMENTATION_PLAN.md` for continuation work and external inputs.
