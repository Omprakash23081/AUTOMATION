WORKSPACE AI SETTINGS

AI provider keys

Keys are scoped to this workspace. YouTube clip ranking tries OpenAI, then Gemini, then Groq, and falls back to a signed-in ChatGPT browser if no API key is configured or every API request fails. Uploaded-audio transcription still requires OpenAI. With `CUTROOM_SECRET_ENCRYPTION_KEY`, keys are encrypted at rest; otherwise, local combined mode keeps them in server memory for this run. Provider usage is billed by the provider.

Get an OpenAI key ↗
OpenAI is used for uploaded-audio transcription and is the primary clip-ranking provider.
Get a Gemini key ↗
Gemini is used for YouTube clip ranking when OpenAI is unavailable or has reached its quota. Owners and admins can manage provider keys.
Get a Groq key ↗
Groq is the final API provider for YouTube clip ranking. If it fails, Cutroom opens the signed-in ChatGPT browser.
